# Check wiki usage (stub)

This skill is a placeholder: MiKode has not yet documented what correct wiki usage
means (which wiki, page structure, naming, when a topic belongs in the wiki versus the
engineering repo).

When invoked:

1. Tell the user this skill is not operational yet because the conventions it would
   check are undefined.
2. Offer to define them: ask which wiki is used, what structure and naming it should
   follow, and what problems prompted the check (stale pages, duplicated content,
   missing pages).
3. If the user defines conventions, record them in the appropriate place — a handbook
   document in `mikode13/engineering` (see its `AGENTS.md` for where guidance
   belongs) — and then replace this stub with real check instructions:
   what to scan, what each violation looks like, and how to report findings.

Do not invent conventions and check against them.
